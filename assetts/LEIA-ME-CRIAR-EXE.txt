PSILOG PARA WINDOWS — COMO GERAR O EXE

Este pacote prepara o Psilog para ser executado como aplicativo desktop com Electron.
O EXE final ainda precisa ser compilado em um computador Windows.

1. Instale o Node.js (versão LTS) em https://nodejs.org/
2. Extraia esta pasta para um local do computador.
3. Abra o Prompt de Comando (CMD) dentro da pasta "psilog".
4. Execute: npm install
5. Para gerar o instalador do Windows, execute: npm run dist:win
6. Para gerar também uma versão portátil, execute: npm run dist:win:portable

Os arquivos serão gerados na pasta "dist".
- Instalador: Psilog Setup 1.0.0.exe
- Versão portátil: Psilog 1.0.0.exe (nome pode variar conforme a versão do builder)

Para testar sem gerar EXE: npm start

IMPORTANTE SOBRE OS DADOS:
O aplicativo mantém os dados no armazenamento local do Electron/Chromium deste
computador. Faça backups pela tela "Dados". Os dados não são sincronizados
automaticamente entre computadores.

O projeto usa Electron e electron-builder. Na primeira execução dos comandos npm,
é necessária conexão com a internet para baixar as dependências.
